# How it works

### For Downloads

- Create the organize or sort folders if it already doesn't exist
- Move the files in the `Downloads` folder into the sort folders
- Go through each sort folder and go through the files
- Delete the files if expired and if not keep

### For Desktop (screenshot management)

- Create the Screenshots folder if it already doesn't exist
- Move the files in the `Desktop`folder into the screenshot folder
- Go through the `Screenshots` folder
- For each folder, delete the files if expired and if not keep
